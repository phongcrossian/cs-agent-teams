## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| frozen snapshots -> ingest | Phase-1 snapshot text (may contain customer examples) enters the store and any ingest logs |
| ingest -> Voyage API | Document text crosses to a third-party embedding API |
| ingest -> Postgres | SQL writes; injection risk if string-formatted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-01-ID | Information Disclosure | ingest logging | mitigate | redact_text() before any log line containing snapshot text (D-06) |
| T-03-01-T | Tampering | pipeline upsert SQL | mitigate | asyncpg `$N` parameterized queries + ON CONFLICT; never f-string SQL |
| T-03-01-HALL | Tampering (data integrity) | threshold storage | mitigate | D-10: thresholds/code-map load as exact rows, never vectorized; test asserts no threshold value in kb_chunk |
