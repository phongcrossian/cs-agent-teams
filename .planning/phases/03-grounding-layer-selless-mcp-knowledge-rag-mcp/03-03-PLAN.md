<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phase-4 caller -> Selless MCP | tool args (order_id/email) untrusted; resolve_order param could attempt free-text browse |
| Selless MCP -> Selless API | gateway-trust: API has NO auth/scope/rate-limit/audit — MCP is the SOLE security boundary |
| Selless MCP -> Postgres audit | redacted-row insert; injection risk if string-formatted |
| raw Selless response -> drafter | DENY fields (payment/cost/supplier) must never cross |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-AC | Elevation / Info Disclosure | resolve_order / tools | mitigate | D-03 keyed-only; resolve_order returns single exact-key identity; raw po/search never exposed; no cross-customer browse |
| T-03-ID | Information Disclosure | whitelist.py + audit.py | mitigate | D-04 hard-deny list as Pydantic model boundary (payment/cost/supplier/payload); D-06 redact_text before any audit/log persist |
| T-03-DoS | Denial of Service | MCP tool surface | mitigate | D-08 RateLimitingMiddleware at MCP boundary (settings-driven rps/burst), independent of Freshdesk limiter |
| T-03-WR | Tampering | ticket-do POST write endpoint | mitigate | D-08 read-only: no write tool registered; all tools readOnlyHint=True; client has no write method |
| T-03-SQLI | Tampering | audit insert | mitigate | asyncpg `$N` parameterized insert; never f-string SQL |
| T-03-V5 | Input validation | tool args | mitigate | Pydantic tool-arg schemas; resolve_order rejects <3-char param |
</threat_model>
