<objective>
Build the offline foundation for FD property write-back: a static enum loader that exposes the
Freshdesk `ticket_fields` choices from the committed snapshot, and a deterministic
classification-to-enum validator/assembler that mirrors the existing allowed-template-codes guard.

(validator + `fd_property_update` assembler), exports added to `src/file_store/__init__.py`, and two
offline test files. No network, no DB, no live Freshdesk write.
