<objective>
Rework the drafter so it (1) selects the correct template via Knowledge MCP `get_template` keyed on the
classifier's `customer_request` sub-type, (2) grounds order eligibility (warranty window, prior-remediation,
variant stock) via Selless before making any offer — using the RD-Q2 PoC stub where a real field is not yet
wired, (3) passes a structured `offer` block to `submit_reply` so `pre_send_guard` can run the D-26
authorized-offer test, and (4) NEVER claims an operational action was executed (RD-Q1), drafting only
non-asserting acknowledgement + the ≤20% retention offer for change_request flows.

Purpose: The reworked guard (04-09) authorizes offers based on a structured offer block; the drafter is the
producer of that block and the place where template-by-sub-type selection and eligibility grounding happen.
The old drafter banned ALL commitment language (D-13); under D-26 it must instead produce policy-bounded
templated offers and hand the guard the evidence to authorize them.
Output: updated drafter agent + ground-and-draft skill + a structural contract test.
</objective>
