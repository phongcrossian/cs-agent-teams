<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| customer email body → LLM prompts | attacker-controllable text; must be delimited as data + screened |
| draft → customer | unauthorized commitments must never reach the wire |
| Knowledge MCP grounding → draft | conflicting/stale policy must not be self-arbitrated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Tampering (prompt injection) | screen_injection / wrap_untrusted on email body (SAFE-04/D-14) | mitigate | deterministic phrase screen escalates on suspicion (Task 1); wrap_untrusted delimits + neutralizes breakout; seed from promptfoo |
| T-04-05 | Elevation (unauthorized commitment) | check_commitment_language on draft (SAFE-04/D-13) | mitigate | deterministic regex blocks send + escalates regardless of category; never auto-strips (Task 1) |
| T-04-06 | Repudiation / wrong-answer | conflict/stale grounding escalation (SAFE-03/D-09) | mitigate | conflict-flag (unless override) + stale-only force escalate (Task 2); pipeline never self-arbitrates policy |
| T-04-07 | Spoofing/high-risk bypass | deterministic money/legal + category escalation (SAFE-03/D-08) | mitigate | any-signal-escalates fail-closed (Task 2) |
</threat_model>
