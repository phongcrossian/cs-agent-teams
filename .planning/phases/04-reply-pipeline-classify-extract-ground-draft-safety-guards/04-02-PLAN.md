  constraints. reply-pipeline encodes stage order + escalation rules + verdict shape; it is the single

Customer-draft chokepoint (design §4a): a draft may ONLY be emitted via the ReplyMCP `submit_reply(body, citations)`
  tool (built in 04-00). The drafter does NOT return free-text as the final reply; it calls submit_reply. settings.json
  binds a PreToolUse hook chain (grounding_check -> pre_send_guard -> final-risk) on submit_reply that BLOCKS (exit 2)
  on any failure; a block is interpreted as the escalate verdict (no draft, D-10).
Verdict shape (Claude's discretion, must stay stable for Phase-5 + worker): action in {draft, escalate};
  draft -> {body, citations:[{id,...}]} (the submit_reply args); escalate -> {reason, risk_signals:[]}.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| email body → every agent prompt | attacker-controllable text reaches classifier/extractor/drafter prompts |
| model output → verdict | draft body crosses toward the (deferred) send path |
| KB/Selless data → draft claims | only cited / whitelisted facts may appear in the draft |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering | email body in agent prompts | mitigate | every agent prompt delimits body as untrusted data (D-14), defense-in-depth with injection_screen hook |
| T-04-02-02 | Information Disclosure | drafter ungrounded claims | mitigate | inline [KB-n]/[SEL-n] citations + grounding_check hook + critic faithfulness dimension (D-11/REP-03) |
| T-04-02-03 | Elevation of Privilege | drafter commitment language | mitigate | agent-local ban + pre_send_guard hook blocks+escalates (D-13/SAFE-04) |
| T-04-02-04 | Spoofing | agent bypassing the workflow | mitigate | escalation enforced by hooks, not by trusting the lead/agents (D-08/D-10/SAFE-03) |
| T-04-02-05 | Information Disclosure | wrong-tier model (Opus) on hot path | mitigate | model-discipline test asserts Haiku/Sonnet only, no Opus (D-03/CLAUDE.md cost rule) |
| T-04-02-06 | Tampering | raw template bodies hard-coded | mitigate | templates fetched via Knowledge MCP get_template at runtime; skills document select/fill only |
</threat_model>
