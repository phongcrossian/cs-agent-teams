<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| customer email body → every LLM prompt | attacker-controllable; delimited as data + injection-screened before any stage |
| Knowledge/Selless MCP → draft | grounding must carry citations; conflict/stale must escalate, not be self-arbitrated |
| draft → customer | no ungrounded claims; no unauthorized commitments; critic must pass |
| pipeline → logs/traces | ticket PII must be redacted before any write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | Tampering (prompt injection) | run_pipeline stage 1 (SAFE-04/D-14) | mitigate | wrap_untrusted + screen_injection before any LLM stage; suspicion early-exits (Task 3) |
| T-04-09 | Information Disclosure (fabrication) | draft + critique (REP-03/D-11) | mitigate | inline citations required; critic faithfulness dim fails unsupported claims -> redraft/escalate (Task 2/3) |
| T-04-10 | Elevation (unauthorized commitment) | output guard before send (SAFE-04/D-13) | mitigate | check_commitment_language blocks+escalates regardless of category; never strips (Task 3) |
| T-04-11 | Spoofing/high-risk bypass | escalation composition (SAFE-03/D-08/D-09/D-10) | mitigate | any-signal (category/rule/missing-key/conflict/stale/guard/critique) -> early-exit verdict, NO draft (Task 3) |
| T-04-12 | Information Disclosure (PII in traces) | trace_stage / logging in run_pipeline | mitigate | redact_text() before every log/trace write (Task 3); tracing attrs redacted (04-00) |
| T-04-13 | Cost/Elevation | per-stage model selection | mitigate | Haiku classify/extract, Sonnet draft/critic; tests assert no Opus id (Tasks 1-2) |
