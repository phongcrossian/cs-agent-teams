## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Freshdesk PROD -> harness | Inbound ticket `description_text` + CS reply are UNTRUSTED attacker-controllable input crossing into the agent prompts (D-14). GET only. |
| Selless PROD -> harness | Read-only order lookup (`/po/search` -> `/po/{id}`); whitelisted summary fields only. No writes. |
| harness -> local files | `test-tickets.xlsx` + `.test-tickets-data.jsonl` carry customer PII; both are gitignored, never committed, never printed raw to stdout (D-04). |
| harness -> Freshdesk (forbidden) | The harness MUST NEVER POST a reply. DRY_RUN asserted; no reply/send path exists (D-39). |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
